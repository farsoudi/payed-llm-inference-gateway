What happens on one request

1 · EDGE
httpapi
Authenticate key, load limits, acquire guardrail slot, read/cap body.
2 · ADMISSION
meter
Reserve the capped max cost in the local cache (402 if it can't cover).
3 · UPSTREAM
ollama
Pin model, forward native NDJSON / SSE frames byte-for-byte.
4 · OBSERVE
ollama + meter
Parse text/usage; exact counts arrive in the terminal event.
5 · SETTLE
ledger
Transactional debit of real usage; release the unused reservation.
6 · FUND (separate)
payment
x402 verify+settle, then credit. Only ever funds the balance.
